MAIN CAM

Drag within the circle - proportional to how far you push, just like the physical controller's stick. Release to stop. POINT-TURN reinterprets the same joystick (left/right only) - see README for the hardware caveat.

Targets are motor steps from the homed zero, which is each joint's own true mechanical center (not the limit switch itself) once calibrated. Slider bounds match each joint's own operational range from rover_description/urdf/arm.xacro (also what arm_mega2.ino's own firmware independently clamps to, and what MoveIt itself already plans within) - a UI-side backstop alongside the firmware's own, not a replacement for it; if arm.xacro's own limits are ever revised, these five slider bounds need updating by hand to match, same as arm_mega2.ino's own kMinDeg/kMaxDeg, since there's no automatic way to share one number across the URDF/firmware/browser boundary. Joint moves are ignored until every joint is individually calibrated - use the buttons above on demand, or wait for the automatic all-5 calibration this board also runs once at startup. The three preset buttons (INITIAL/TRANSPORT/SERVICE POSITION) currently all move to the same all-zero pose (now genuinely meaningful - every joint at its own true center, not an arbitrary placeholder position) - real, distinct poses for TRANSPORT/SERVICE are still pending bench calibration in arm_mega2.ino's own firmware constants.

Return Home sends the head to 0°/0°. Transport Position sends it to whatever's configured in mast_topology.yaml's transport_head_yaw_deg/transport_head_pitch_deg - not necessarily the same as 0/0, and doesn't touch the lift by itself, so sequence with Stow (Transport) above as your own setup needs. After calibration finishes, the head automatically sweeps to a verification position, returns to 0°/0°, and disables its own drivers - "CLOSE DRIVER (ENABLE)" re-enables them for manual control afterward.

High-gain-antenna gimbal, modeled on the real MER (Spirit/Opportunity) HGA - G1 (azimuth) is normal to the deck, G2 (elevation) is parallel to it. Operational range (15°-285° azimuth, 0°-180° elevation) is a real, bench-confirmed post-deployment limit, not a placeholder - see README's "Explicit assumptions" for the research behind it. Drivers start disabled after homing until you press "CLOSE DRIVER (ENABLE)".
